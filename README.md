# AUTO LAB · v4 车辆重建

纯前端的智能驾驶汽车科普应用。入口为 index.html；黑蓝紫主题、20 版历史报纸、硬件拆解、系统透视、部件选择和四座内饰保留。

## 智驾简史报 · 20 版增刊

`#history` 现在是一份可分页阅读的报纸式编年史，共 20 版，从 1955—1956 年人工智能研究议程、感知机与 Shakey，经过 ABS、超声波、雷达、Navlab、DARPA 挑战、Deep Blue，再到 ImageNet、AlexNet、KITTI、端到端驾驶、AlphaGo、Transformer、BERT、nuScenes、BEVFormer、UniAD 与 EMMA（历史回顾收在 2024 年首发研究）。

每版包含四段主文、编辑旁注、技术小讲堂、一个可带入 3D 实验室的问题，以及 1—3 个原始论文或机构档案链接。档案照片只在来源已明确的版面使用；其余版面使用页面内自行绘制的原理示意图，并标注“非历史照片”。目录、下拉跳转、上一版/下一版、进度条和当前浏览器会话记忆都由 `index.html` 内的原生 JavaScript 驱动。

本增刊的文字是对原始资料的中文科普改写，不把研究车实验写成量产能力，也不把棋类或通用 AI 成果直接等同于道路安全。来源与图片出处写在每个版面的右栏。

## 本次重建

车身替换为连续截面生成的跨界车曲面，乘员舱为实际下凹空间。风挡、全景车顶、后挡、侧窗均独立生成厚度；窗带、门缝、齐平把手、后视镜、细灯组与下包围跟随车体基准。四轮包含旋转截面轮胎、开口轮圈、整体双分叉轮辐、深色制动盘和卡钳。内饰包含弧面座椅、头枕、缝线、仪表台、方向盘、屏幕和扶手。

传感器改为集成布置：风挡内侧摄像头、前保险杠后的毫米波雷达、车顶前缘低矮光学整流罩内的固态 LiDAR。组装态收敛外观，拆解后展示教学模块。LiDAR 的逻辑视场为前向 120°扇区。模型无车标，属于参考 Model Y 轮廓并融合其他跨界车细节的教学概念设计。

单位为米，车头 -X、上方 +Y。车长 4.92，轴距 3，轮胎半径 0.405，轮拱半径 0.465。四座为 2 + 2 教学布局；参数和布置不代表任何量产车型的配置。

## 运行

直接打开 index.html，或在此目录运行：

```powershell
$env:PORT = '4188'
node preview.cjs
```

预览地址：http://127.0.0.1:4188/#lab 。诊断入口：/?debug=1#lab 。

Three.js 固定为 0.180.0，GSAP 固定为 3.12.5，经 CDN 加载。模型没有外部模型或纹理依赖；历史图像是远程引用。单文件静态部署需要联网。

## 项目结构

- index.html：完整 HTML/CSS/JavaScript 应用（含 20 版历史报纸与 3D 实验室）。
- history20.js：20 版报纸的独立编辑源文件；发布时已嵌入 index.html，便于单文件静态部署。
- research-history.mjs：只读来源检查脚本，用于核阅机构页面与原始论文的可访问性。
- verify-history.mjs：本地 Chrome 回归脚本，检查模块语法、20 版选项、无横向溢出和控制台错误。
- preview.cjs：可选本机静态服务器。
- VALIDATION.md：本轮实测和限制。
- DESIGN-REFERENCES-v4.md：官方外观图片来源与设计取舍。
- GEOMETRY-AUDIT-v4.json：未合并及合并后几何检查。
- audit-v4.mjs：离线审计脚本，需要本机 Three.js 模块和几何技能检查器。
- preview-v4-*.png：本轮实际浏览器截图。
- references-v4/：仅用于建模参考的官方照片，不参与网页运行。
- index.pre-v4.html：本轮改动前备份。

## 核心实现

DATA 存放 10 个部件的文案、锚点和展开位移。每个语义部件独立 Group，home 保存原位；animateAssembly() 用可打断的 GSAP 动画移动至 home + delta，复原回到 home。四轮有各自的原位和横向展开目标。

bodyRing() 从共享肩线、宽度、轮拱和乘员舱基准生成连续车身。panel() 为玻璃及饰件生成外层、内层与回边。checkedGeometry() 检查自定义闭合网格的坐标、边使用次数、退化三角形和体积。命名网格保留到审计，再按语义部件与材质合并。

Raycaster、DOM 锚点和部件索引统一调用 selectPart()；相机聚焦使用独立动画，动画结束后交回 OrbitControls。系统透视复原空间关系并降低结构层透明度，显示感知、决策、执行数据流。技术参数和可视化范围为科普示意。

## 操作

拖动旋转，滚轮缩放，右键平移。A/B 切换模式，空格拆解或组装，R 重置，T 俯视，Esc 退出聚焦。诊断视图提供线框、法线、质量档位与固定机位。

本轮使用 3dviz-pro-max、threejs-procedural-geometry 与 three-best-practices 的造型、装配关系和性能建议；实际验收结果以 VALIDATION.md 为准。
